## Как опубликовать

1. wp-admin → **Posts → Add New**
2. **Title:** копируем из заголовка первой строки md-файла
3. **Permalink:** ставим slug из имени файла (без `.md`)
4. **Content:** в режиме «Code editor» вставляем тело markdown (Gutenberg сам преобразует)
   - Или используем плагин **Markdown for WordPress** для нативного рендера
5. **Excerpt** — копируем поле `Excerpt:` из метаданных статьи
6. **SEO** — если стоит Yoast/RankMath:
   - SEO title: из поля `Title:`
   - Meta description: из поля `Description:`
7. **Categories:** Создать категорию из поля `Категория:`
8. **Tags:** добавить из поля `Теги:`
9. **Featured image:** добавить релевантную картинку (или сгенерировать AI)
10. **Publish** → проверить, что отображается на `/blog/`

Рекомендованный темп: **1 статья в неделю**:
- Неделя 1: 01-kak-sekonomit
- Неделя 2: 02-parking-vs-taxi
- Неделя 3: 03-chto-ne-ostavlyat
