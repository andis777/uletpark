Превью виджета брони

Этот калькулятор встраивается на uletnayaparkovka.ru как Custom HTML блок. Подключён к боевому api.uletnayaparkovka.ru

Что попробовать

  • Переключи Парковка ↔ Ночёвка — цена пересчитается
  • Поменяй даты — расчёт идёт live через POST /api/calc
  • Введи имя + телефон, нажми «Забронировать»
  • Submit идёт в POST /api/leads → amoCRM (STUB) + Telegram + Email
  • В STUB-режиме сделка создаётся виртуально, но видна в логах сервера
  • Открой DevTools (F12) → Network → увидишь все вызовы

Тест без формы

  • В консоли (F12) можешь напрямую:
fetch("https://api.uletnayaparkovka.ru/api/leads",{
  method:"POST",
  headers:{"Content-Type":"application/json"},
  body:JSON.stringify({
    name:"Тест",
    phone:"+79991234567",
    service:"parking",
    dateFrom:"2026-06-01",
    dateTo:"2026-06-05",
    source:"console"
  })
}).then(r=>r.json()).then(console.log)

Что готово

  • ✅ /api/calc — расчёт цены на сервере
  • ✅ /api/leads — приём заявок
  • ✅ amoCRM создание (в STUB до получения токенов)
  • 🟡 Telegram — нужен TELEGRAM_BOT_TOKEN
  • 🟡 Email — нужен SMTP_*
  • ✅ UTM-сбор из URL
  • ✅ Rate limit 20/мин на IP
  • ✅ CORS открыт для uletnayaparkovka.ru
