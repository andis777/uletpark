## 5. Что важно для модерации (риски и как закрыть)

### App Store (Apple Review Guidelines)

| Риск | Решение |
|---|---|
| 4.2 (Minimum Functionality) — слишком простой | В описании показали 7+ функций, есть лояльность, тарифы, доп.услуги |
| 5.1.1 (Privacy Data Collection) — собираем телефон | Privacy Policy ссылается прямо в логине + декларация в App Privacy |
| 5.1.5 (Location Services) — не используем | Если запросим геолокацию — указать в Info.plist `NSLocationWhenInUseUsageDescription` |
| Sign-in flow без альтернативы | Apple требует "Sign in with Apple" если есть соц. сети. У нас только SMS — это нормально |
| ATS cleartext exception | Закрыто `NSExceptionDomains` только для нашего API. Apple не любит, но проходит. **Лучше**: поставить Let's Encrypt на api.uletnayaparkovka.ru |

### RuStore

| Риск | Решение |
|---|---|
| Иконка не совпадает с витриной | Везде одна `icons/icon-1024.png` |
| SMS не приходит | sms.ru настроен, баланс 145₽, тест прошёл |
| Правовые документы недоступны из логина | 3 кликабельные ссылки в логине |
| 152-ФЗ (хранение ПДн в РФ) | Сервер в РФ (194.87.222.67), Postgres в РФ |

### Google Play

| Риск | Решение |
|---|---|
| Data Safety не заполнена | Заполнить по таблице выше |
| Target API level < 34 | Проверить в `app.json` `compileSdkVersion`/`targetSdkVersion`, в SDK 52 = 35/34 — ОК |
| Sensitive permissions | Запрашиваем только SMS, push, internet — все базовые |
