# Ready-to-deploy пакет — что копировать и куда

Все материалы в этой папке готовы к публикации. Тебе не нужно их редактировать —
просто копируй и вставляй по инструкции ниже.

**Логика:** uCalc → amoCRM остаётся как есть. Мы НЕ заменяем основной поток
заявок. Мы добавляем **рядом** усиления (доверие, поп-апы, sticky CTA), которые
**ведут к тому же uCalc-калькулятору**. Конверсия растёт без замены технологии.

---

## ЭТАП 1 — Сегодня (1-2 часа)

### 1.1. Установить Yoast SEO в WordPress (если ещё нет)

`wp-admin → Плагины → Добавить новый → найти «Yoast SEO» → Установить → Активировать`

### 1.2. Прописать метатеги на 19 страницах

Открыть `metatags/metatags-all-pages.md` — там для каждой страницы готовые
**SEO Title** и **Meta Description**. Для каждой страницы:

1. `wp-admin → Страницы → найти нужную → Редактировать`
2. Прокрутить вниз до блока **Yoast SEO**
3. Скопировать SEO Title и Meta Description из нашего файла
4. **Обновить**

Время на одну страницу: 30 секунд. Всего: 10 минут.

### 1.3. Вставить Schema.org разметку

Открыть `wp-blocks/05-schema-org.html` — скопировать ВСЁ содержимое.

В WordPress:
1. `wp-admin → Внешний вид → Виджеты` (или Customizer)
2. Найти раздел «Header / Подвал» (зависит от темы)
3. Вставить в **Custom HTML виджет в подвал**
4. Сохранить

Альтернатива (более правильная):
1. Установить плагин **Insert Headers and Footers**
2. `Настройки → Insert Headers and Footers → Scripts in Footer`
3. Вставить туда содержимое нашего файла
4. Сохранить

Проверка: через 1 час после установки прогнать через
https://search.google.com/test/rich-results — должна быть отметка
«Parking Facility» и «FAQPage» как валидные.

### 1.4. Вставить блок «Trust-bar» на главную

Открыть `wp-blocks/01-trust-bar.html` — скопировать содержимое.

В WordPress:
1. `wp-admin → Страницы → Главная → Редактировать`
2. Добавить блок **Пользовательский HTML** в самое верх (выше калькулятора uCalc)
3. Вставить код
4. **Обновить**

### 1.5. Вставить баннер «Не успели на самолёт»

Открыть `wp-blocks/02-guarantee-banner.html`.

В WordPress: добавить блок Custom HTML на главную **между калькулятором и
блоком с услугами**.

### 1.6. Включить Sticky CTA

Открыть `wp-blocks/03-sticky-cta.html` — это блок который показывается
в подвале на мобильных при скролле.

В WordPress:
1. `wp-admin → Внешний вид → Виджеты → Подвал`
2. Добавить Custom HTML виджет
3. Вставить наш код
4. Сохранить

### 1.7. Включить Exit-intent поп-ап

Открыть `wp-blocks/04-exit-intent-popup.html` — это код поп-апа что
срабатывает при попытке закрыть страницу.

В WordPress: добавить в тот же подвальный Custom HTML виджет где
sticky CTA.

## ЭТАП 2 — На этой неделе (2-3 часа суммарно)

### 2.1. Я.Бизнес — обновить карточку

1. https://business.yandex.ru/cabinet → Моя организация → «Улётная»
2. **Описание организации** — обновить, использовать ключевые слова
   из метатегов и текстов в `wp-blocks/02-guarantee-banner.html`
3. **Услуги** — добавить:
   - «Парковка от 1 суток — от 300 ₽»
   - «Парковка от 4 суток — от 1750 ₽»
   - «Парковка на месяц — от 4500 ₽»
   - «Ночёвка 6 часов — 500 ₽»
   - «Ночёвка 12 часов — 800 ₽»
   - «Сутки в номере отдыха — 1200 ₽»
   - «Бесплатный трансфер» — выделить как акция
4. **Фото** — добавить минимум 10 фото (если есть, иначе закажи фотографа)
5. **Время работы** — 24/7
6. **Особенности** — отметить: Wi-Fi, договор хранения, видеонаблюдение,
   трансфер, охрана

### 2.2. Программа сбора отзывов

Опубликовать в группе клиентов / отправить SMS-ом всем кто бронировал
за последний месяц:

```
{{firstName}}, вы недавно были у нас на парковке. Поделитесь впечатлениями —
оставьте 1 предложение на Яндекс.Картах. В благодарность — 500 баллов
на следующую бронь.

Ссылка: https://yandex.ru/maps/-/CDEM5L~D
```

Цель: довести с 100 до 200+ отзывов за месяц.

### 2.3. Подготовка к Я.Директу

1. Открыть `ads/yandex-direct-ads.md` — там 20 готовых объявлений по
   5 кампаниям
2. Создать аккаунт в Я.Директе (если нет) → https://direct.yandex.ru
3. Подключить Я.Кассу для оплат
4. **Не запускать сразу** — сначала нужно настроить цели в Я.Метрике
   (см. этап 3)

## ЭТАП 3 — На следующей неделе (1 день)

### 3.1. Подключить Яндекс.Метрику + цели

1. Создать счётчик на https://metrika.yandex.ru если нет
2. Установить код Метрики в подвал сайта через **Insert Headers and Footers**
3. Создать цели:
   - `calc_opened` — JS-цель «открытие калькулятора» (по клику)
   - `calc_submitted` — JS-цель «отправка заявки в uCalc» (по событию)
   - `phone_click` — клик по телефону
   - `app_download` — клик «Скачать в RuStore»
   - `exit_intent_submit` — отправка формы в поп-апе
4. Подключить Я.Вебмастер на ту же Метрику

### 3.2. Запустить Я.Директ

С небольшим бюджетом для тестов:
- Кампания 1.1 «парковка шереметьево» — 500 ₽/день
- Кампания 4 «ремаркетинг» — 200 ₽/день

Через 7 дней анализ:
- Стоимость заявки < 350 ₽ — продолжаем и увеличиваем бюджет
- CTR < 3% — переписать объявления
- CR < 10% — проверить страницу куда ведёт реклама

### 3.3. Настроить ASO в RuStore

1. Открыть `aso/app-store-listing.md`
2. Зайти в кабинет RuStore: https://console.rustore.ru/apps/2063713783
3. Обновить:
   - Название → как в файле
   - Краткое описание → копировать
   - Полное описание → копировать
   - Ключевые слова в категории
   - Скриншоты (загрузить новые если есть)
4. Сохранить и отправить на ревью

## ЭТАП 4 — В течение месяца

### 4.1. Подключить email-цепочку

1. Зарегистрироваться в Unisender — https://unisender.com (бесплатный тариф)
2. Открыть `email/welcome-chain.md`
3. Создать 5 шаблонов писем по нашему контенту
4. Настроить триггеры:
   - Письмо 1 — сразу после создания брони (webhook от amoCRM)
   - Письмо 2 — за 24 часа до даты заезда
   - Письмо 3 — через 2 часа после даты выезда
   - Письмо 4 — через 7 дней
   - Письмо 5 — через 30 дней

### 4.2. Подключить колл-трекинг

Сервис: Callibri (4-8 тыс ₽/мес) — https://callibri.ru

Установить код Callibri в подвал сайта. После этого каждый звонок
будет привязан к каналу (Я.Директ, органика, прямой и т.д.) и
ты увидишь полную картину.

### 4.3. Запустить VK Ads и Telegram Ads

После 30 дней Я.Директа когда понятно что работает — расширить на VK и
Telegram. Тексты будут такие же как в `ads/yandex-direct-ads.md`, только
переформатировать в формат каруселей.
