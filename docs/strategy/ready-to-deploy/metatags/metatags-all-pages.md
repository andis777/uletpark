# Метатеги для всех страниц uletnayaparkovka.ru

## Куда вставлять
В Yoast SEO / RankMath / Все-в-одном SEO плагине — поля **SEO Title** и **Meta Description** для каждой страницы.

Если SEO-плагина нет — поставить **Yoast SEO** (бесплатный), занимает 5 минут.

## Правила
- **Title** — до 60 символов, ключевые слова в начале
- **Description** — до 160 символов, призыв к действию + цифра + бренд
- **Не дублировать** между страницами

## Проверка после внедрения

Через 1-3 дня после обновления:

1. **Я.Вебмастер** → Проверка ответа сервера → должен быть `<meta name="description">` с новым текстом
2. **Google Search Console** → URL Inspection → видны новые теги
3. **Поиск в Яндексе** через 7-14 дней начнёт показывать новые сниппеты
4. **CTR из выдачи** через 30 дней — должен вырасти на 15-25%
