## 1. КЛИЕНТ — физическое лицо (главная воронка)

### Customer Journey

```
Узнаёт → Заходит на сайт/приложение → Выбирает услугу
       → Считает цену → Бронирует → Получает SMS/email
       → Приезжает → Оставляет машину → Летит
       → Возвращается → Получает машину
       → Получает баллы → Возвращается через 3-6 мес
```

### Что работает end-to-end ✅

| Этап | Статус | Где |
|---|---|---|
| Узнаваемость (бренд, SEO) | ⚠️ частично | WordPress сайт (старый) есть, но без свежих оптимизаций |
| Сайт-конверсия (форма брони) | 🟡 готов виджет | `deploy/wordpress/booking-widget.html` — не залит на основной сайт |
| Калькулятор цены | ✅ | `POST /api/calc` — точно по uCalc формулам |
| Создание заявки | ✅ | `POST /api/leads` — отдаёт в amoCRM+TG+Email |
| Mobile приложение | ✅ | Expo, в RuStore live, в App Store на review |
| SMS-авторизация | 🟡 stub | код `111111`, нужен SMS.ru API ID |
| Личный кабинет | ✅ | профиль, история броней, баллы, рефералка |
| Бронь через app | ✅ | parking + nochevka wizards |
| Программа лояльности | ✅ | 1₽=1балл, тиры bronze/silver/gold |
| Реферальная программа | ✅ | код в приложении + бонусы |
| Удаление аккаунта (App Store) | ✅ | `DELETE /api/me` + UI с двойным confirm |

### Что осталось 🔴

| # | Что | Приоритет | Где сделать |
|---|---|---|---|
| 1 | **Залить booking-widget на WordPress** (страницы парковка + ночёвка) | 🔥 P0 | `wp-admin → Pages → Custom HTML` |

| 3 | **Telegram-бот + chat_id** в env | 🔥 P0 | `.env.production` (см. notifications-setup.md) |
